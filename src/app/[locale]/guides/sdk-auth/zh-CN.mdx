## API令牌

登录的速率限制通常低于其他 API 操作的速率限制。短时间内多次调用登录方法可能会触发限速。您只需在每个会话中调用一次登录方法即可进行身份验证。

登录方法调用的“com.atproto.server.createSession” API 端点返回一个包含两个 API 令牌的会话对象：
* `accessJwt`：用于验证请求的访问令牌，但几分钟后就会过期
* `refreshJwt`：刷新令牌，持续时间更长，仅用于使用新的访问令牌更新会话
